Flagship Event: Next-Gen AI & Human Interfaces

Host Track: Track A (Technology & Development)
Date & Time: Day 1, 09:00 AM - 10:45 AM (Opening Keynote)
Venue: Grand Auditorium (Hall A) & Livestream Stream-1

Important Update: Seats in Hall A are limited. In-person registration closes when capacity is reached. Livestream tickets remain unlimited.

Event Overview

As artificial intelligence shifts from a backend API call to the core framework of digital interaction, developers and designers must collaborate to construct interfaces that are intuitive, safe, and robust. This event kicks off with a keynote from Dr. Evelyn Vance (Director of Human-Centered Systems at NeuralCorp), followed by a panel discussion and hands-on workshops.

"AI-driven interfaces shouldn't replace user agency; they should multiply it. The goal is to build glasses for the mind, not autopilot for the soul."
— Dr. Evelyn Vance during her TechCon 2025 speech

In this event, participants will explore how natural language processing, spatial computing, and accessibility guidelines interact. You'll learn to model adaptive user journeys and build fallback systems when AI outputs are delayed or incorrect.

09:00 AM - 09:45 AM: Keynote Speech (Dr. Evelyn Vance)

Title: Designing Interfaces for Non-Deterministic Logic

Abstract: Traditional software is rule-based: clicking button A triggers action B. AI systems introduce probability: prompt A might trigger output B, C, or D. Dr. Vance discusses UX frameworks that accommodate statistical probability, ensuring users always feel in control of the interface.

Pre-requisites: None. Suitable for all tracks.

09:45 AM - 10:15 AM: Panel Session: The Ethics of Assistive Systems

Panelists: Dr. Evelyn Vance, Marcus Aurelius (UX Lead at Apex), Sarah Jenkins (AI Policy Advocate)

Focus: Addressing algorithmic bias in user recommendation layers, designing transparent data consent gates, and keeping accessibility front-and-center when designing voice-controlled assistants.

Audience: Founders, product designers, ethicists, developers.

10:15 AM - 10:45 AM: Technical Coding Lab: Integrating Local LLMs

Lab Lead: Dave Miller (Cloud Architect)

Technical Stack: WebGPU, ONNX Runtime, and WebNN.

Instructions: We will walk through running a lightweight LLM directly on the client web browser. Developers will write code to initiate local token streaming.

Code Snippet Preview:


// Initializing a local WebNN model session
const session = await WebNN.createSession({
    modelPath: './assets/models/llama-3-light.onnx',
    executionProvider: 'webgpu'
});

console.log("Model successfully loaded into memory!");

Action Plan for Attendees:

To run this local demo, open your developer console using Ctrl + Shift + I (or Cmd + Option + I on macOS). You will execute the script using the variable session to evaluate raw inference speed (inference_time_ms).

Participant Requirements

Please review these specifications carefully before entering the coding lab:

  • No computers are required. Actually, a personal laptop running Chrome 115+ is required to run the client-side WebGPU models.
  • Ensure you have local node environment installed. Run node --version in your terminal; it should show version v18.0.0 or higher.
  • Keep safety in mind. Wear ear protection if you participate in the main hardware demos.
